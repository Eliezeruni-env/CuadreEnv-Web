¿Cómo funciona la Recepción de Mercancía?

Una Orden de Compra representa el pedido acordado con el proveedor. En este módulo, el personal de almacén realiza el conteo físico real de los productos al momento de recibirlos del camión o transportista. Al confirmar la recepción, el inventario del almacén seleccionado se incrementa de inmediato. Si el conteo coincide exactamente, se completa la orden; si hay variaciones (sobrantes o faltantes), se envía a la Bandeja de Aprobaciones para auditoría de un supervisor.
